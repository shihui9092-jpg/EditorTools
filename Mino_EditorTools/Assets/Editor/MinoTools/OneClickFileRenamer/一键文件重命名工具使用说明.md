# 一键文件重命名工具 — 使用说明

工具代码位于 **`Assets/Editor/OneClickFileRenamer/`**，不影响运行时构建；仅用于 Unity 编辑器内批量重命名工程资源文件。

---

## 如何打开

在 Unity 菜单栏选择：

**`Tools` → `命名工具` → `一键更改文件名`**

---

## 作用范围

- 在 **Project** 视图中 **当前选中** 的内容决定待处理列表。
- 可只选中 **文件**；也可选中 **文件夹**（见下方「递归」选项）。
- 工具改的是 **磁盘上资源文件名**（不含扩展名的那一段会参与 `RenameAsset`），**不会**单独改文件夹名（文件夹仅用于收集其下的文件）。

---

## 推荐操作流程

1. 在 Project 中选中要批处理的文件或文件夹。
2. 打开本工具窗口。
3. 选择 **重命名模式** 并填写参数。
4. 根据需要打开 **扩展名过滤**、**递归** 等选项。
5. 在窗口下方 **预览**：确认 `旧名 -> 新名` 列表无误。
6. 点击 **一键重命名**。

可随时点 **刷新选择** 重新根据当前 Project 选中项生成列表。

---

## 重命名模式说明

| 模式 | 说明 |
|------|------|
| **前缀后缀** | 在 **去掉扩展名后的文件名** 两端追加「统一前缀」「统一后缀」。 |
| **文本替换** | 将原名中的「查找文本」全部替换为「替换文本」（字符串替换，非正则）。 |
| **正则替换** | 使用 .NET 正则对 **无扩展名的文件名** 做 `Regex.Replace`。表达式错误时窗口会显示红字提示。 |
| **序号命名** | 将文件依次命名为 `基础名` + `连接符` + 序号（可按位数补零），最后再套统一前缀/后缀。 |

**注意：**「统一前缀」「统一后缀」在所有模式下都会最终套用到名字上（序号模式同样会先算出 `modeName` 再加前后缀）。

## 常用选项

### 包含选中文件夹内文件（递归）

- **勾选**：选中文件夹时，会递归收集该文件夹下 **所有文件**（不含子文件夹本身）。
- **取消**：选中文件夹时，**不会**因该文件夹而加入任何文件（只有直接选中的文件会进入列表）。

### 包含 .meta 文件

- 默认 **不** 重命名 `.meta`。
- 若勾选，则 `.meta` 也会按同样规则参与重命名。  
  **一般不建议** 随意改 `.meta` 文件名；除非你明确知道后果并做好备份或版本管理。

### 启用扩展名过滤

- **勾选** 后，只有扩展名在列表内的文件会进入待处理列表。
- 列表写法示例：`.png,.prefab,.mat` 或 `png,prefab,mat`（可混用逗号、分号、竖线或空格分隔）。
- 若已启用过滤但 **没有填写任何有效后缀**，窗口会 **黄色提示**，并 **禁用「一键重命名」**，避免误操作。

---

## 同名冲突

若目标目录下已存在同名文件，工具会自动在名字后追加 `_1`、`_2` … 以尽量不重名（仍会尽量保留你设定的新名主体）。

---

## 注意事项与风险

1. **版本控制**：大批量改名会产生大量 Git 变更；提交前请确认 diff。
2. **引用关系**：Unity 多数资源通过 **GUID**（在 `.meta` 中）引用，**通常** 仅改 `xxx` 主文件名仍会保留引用；但若你们工作流里有 **写死路径/字符串** 的资源加载方式，可能受影响。
3. **脚本类名**：若重命名的是 **脚本文件**，文件名与 **public 类名** 不一致可能导致编译错误，需手动调整类名或改回文件名。
4. **先做小范围试运行**：可先选一个子文件夹、少量资源验证预览再执行全量。
