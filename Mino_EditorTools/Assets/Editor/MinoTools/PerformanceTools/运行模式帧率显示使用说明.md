# 运行模式帧率显示 使用说明

## 1. 工具定位

在 **Play Mode** 与 **打包后的 Player** 中，于 **Game 画面** 叠加显示帧率与性能指标（IMGUI，可配置位置与内容）。

| 环境 | 是否支持 |
|------|----------|
| 编辑器 Play Mode | 支持 |
| Development 打包 | 总开关开启即显示 |
| Release 正式打包 | 总开关 + 「发布包也显示帧率」 |

**版本：v1.1 + v1.2**

菜单入口：

- **Tools → MinoTools → 性能工具 → 运行模式帧率显示**
- **Tools → MinoTools → 性能工具 → 发布包也显示帧率**

---

## 3. 使用方法

### 3.1 编辑器 Play Mode

1. 菜单 **运行模式帧率显示** 保持勾选（默认开）。
2. 进入 Play Mode，按配置在屏幕角落显示面板。
3. 按 **F1**（默认）可临时隐藏/显示面板（不改变总开关）。
4. 退出 Play Mode 后自动销毁，无残留。

### 3.2 打包后在其他平台

1. 在 Project 中打开配置资源（见下节），或使用菜单设置总开关 / Release 开关。
2. **保存工程** 后打包；配置随 `Resources` 进入 Android / iOS / PC 等 Player。
3. **Development Build**：总开关开即可。
4. **Release 包**：须勾选 **发布包也显示帧率**。

### 3.3 配置资源路径

`Assets/MinoTools/Runtime/Resources/MinoToolsRuntimeFpsBuildSettings.asset`

首次打开工程若不存在，编辑器会自动创建。

## 4. 显示指标（v1.1 / v1.2）

| 指标 | 说明 | 配置字段 |
|------|------|----------|
| **FPS** | `unscaledDeltaTime` 平滑值 | `showFps` |
| **MS** | 帧间隔毫秒 | `showMs` |
| **Min / Max** | 统计窗口内最低/最高 FPS | `showMinMaxFps`、`sampleWindowSeconds` |
| **1%L** | 最差 1% 帧平均 FPS（卡顿参考） | `show1PercentLowFps` |
| **目标 / VSync** | `targetFrameRate` 与 `vSyncCount` | `showTargetFrameRate` |

- 统计基于环形缓冲，窗口长度默认 **3 秒**（`sampleWindowSeconds`）。
- 颜色阈值：`greenFpsThreshold`（默认 55）、`yellowFpsThreshold`（默认 30）；文字色为绿 `#00CB26`、黄 `#C2CB00`、红 `#FF0000`。

---

## 5. 布局与交互（v1.1 / v1.2）

无背景框，仅在屏幕角落叠加彩色文本（`margin` 控制与边缘距离）。

| 配置项 | 说明 | 默认 |
|--------|------|------|
| `anchor` | 文本锚点：左上 / 右上 / 左下 / 右下 | 右上 |
| `margin` | 相对安全区边距（像素） | 10 |
| `useSafeArea` | 使用 `Screen.safeArea`（刘海屏） | 开 |
| `fontSize` | 字号 | 14 |
| `panelScale` | 面板缩放 | 1.0 |
| `enableHotkeyToggle` | 运行时热键切换显示 | 开 |
| `toggleHotkey` | 热键（默认 F1） | F1 |

热键仅切换 **当前运行会话** 的面板可见性，不修改 `.asset` 总开关。

---

## 6. Inspector 配置说明

选中 `MinoToolsRuntimeFpsBuildSettings.asset` 后可调整：

- **开关**：`enableDisplay`、`showInReleaseBuild`
- **显示项**：勾选需要展示的指标行
- **布局**：锚点、边距、安全区、字号、缩放
- **颜色阈值**：绿 / 黄分界 FPS（文字色 `#00CB26` / `#C2CB00` / `#FF0000`）
- **统计**：`sampleWindowSeconds`
- **热键**：是否启用、`toggleHotkey`

修改后 **保存** 再打包，即可带到目标平台。

---

## 7. 与「Game窗口帧率显示」的区别

| 工具 | 场景 |
|------|------|
| **运行模式帧率显示** | Play Mode + 真机/Player，功能完整 |
| **Game窗口帧率显示** | 仅编辑器 Game 视图钩子，易因版本失效 |

多平台性能验证 **请以本工具为准**。

---

## 8. 注意事项

1. IMGUI 开销很小；低配机可关闭部分显示项或总开关。
2. Release 包默认不显示，避免误上线；需 QA 时勾选「发布包也显示帧率」。
3. Player 下宿主 `DontDestroyOnLoad`，跨场景持续显示。
4. 移动端请将 `useSafeArea` 保持开启，避免面板被刘海遮挡。
5. 热键在编辑器与 PC 玩家上有效；部分 Android 无键盘时可关闭热键或后续扩展手势。

---

## 9. 常见问题

**Q：打包后没有显示？**  
A：检查 Release 是否勾选「发布包也显示帧率」、总开关、`enableDisplay` 是否为 true。

**Q：1%L 与 FPS 差别大？**  
A：正常；1%L 反映最差 1% 帧，更能体现卡顿尖峰。

**Q：面板被刘海挡住？**  
A：开启 `useSafeArea`，或增大 `margin`、改 `anchor`。

**Q：按 F1 无反应？**  
A：确认 `enableHotkeyToggle` 为 true，且 `toggleHotkey` 未与其它逻辑冲突。
