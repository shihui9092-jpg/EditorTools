# TransformQuickResetInspector 说明文档

## 1. 脚本定位与主要作用

`TransformQuickResetInspector` 是一个 Unity Editor 自定义 Inspector 脚本，用于替换 `Transform` 的默认检视面板，提供以下能力：

- 在 Inspector 中直接编辑本地 `Position / Rotation / Scale` 三轴值。
- 提供 `P / R / S` 一键复位按钮：  
  - `P`：位置复位为 `(0,0,0)`  
  - `R`：旋转复位为 `(0,0,0)`（四元数 `identity`）  
  - `S`：缩放复位为 `(1,1,1)`
- 支持多选对象批量编辑，并处理多选状态下旋转轴不一致的显示逻辑（显示 `--`）。

该工具适用于场景搭建、UI 布局、预制体规范化等高频需要“快速归零/归一”的编辑场景。

---

## 2. 当前脚本结构

- `OnEnable()`  
  缓存 `Transform` 的序列化属性：`m_LocalPosition`、`m_LocalRotation`、`m_LocalScale`。

- `OnInspectorGUI()`  
  统一驱动 Inspector 绘制流程：`DrawPosition()`、`DrawRotation()`、`DrawScale()`。

- `DrawPosition()` / `DrawScale()`  
  绘制 XYZ 输入框和 P/S 复位按钮。

- `DrawRotation()`  
  绘制旋转输入框和 R 复位按钮；处理多选对象时各轴差异；仅覆写被编辑的轴值。

- `RegisterUndo()`  
  在旋转手动编辑时登记 Undo，保证可撤销。

## 3. 已执行的优化项（不改功能）

本次仅进行“优化方案”，未引入新功能扩展：

1. **命名优化**
   - 类名由 `SUGUITransformInspector` 调整为 `TransformQuickResetInspector`，语义更贴近“Transform 快速复位 Inspector”。
   - 脚本文件名同步为 `TransformQuickResetInspector.cs`，与类名一致，降低维护成本。

2. **可维护性优化**
   - 将按钮宽度、旋转输入最小宽度、浮点比较阈值提取为常量：
     - `ResetButtonWidth`
     - `RotationFieldMinWidth`
     - `FloatDifferenceThreshold`
   - 序列化字段命名由 `mPos/mRot/mScale` 优化为语义化名称：
     - `localPositionProperty`
     - `localRotationProperty`
     - `localScaleProperty`

3. **Inspector 状态安全优化**
   - `OnInspectorGUI()` 中对 `EditorGUIUtility.labelWidth` 做缓存与恢复，避免影响其他 Inspector 绘制。

4. **GUI 变更检测优化**
   - `FloatField()` 从 `GUI.changed` 迁移到 `EditorGUI.BeginChangeCheck()/EndChangeCheck()`，减少全局状态副作用。

5. **布局写法优化**
   - 使用 `EditorGUILayout.HorizontalScope` 替代 `BeginHorizontal/EndHorizontal`，提升代码安全性与可读性。

## 4. 使用说明

1. 将脚本放在 `Assets/Editor` 目录下（当前路径已满足）。
2. 回到 Unity 后等待编译完成。
3. 在 Hierarchy 中选中任意对象，查看其 `Transform` 组件：
   - 可直接编辑 XYZ
   - 可点击 `P/R/S` 快速复位
4. 多选对象时：
   - 当某轴值不一致，会以 `--` 提示。
   - 仅对你手动修改的轴执行批量写入。

---

## 5. 注意事项

- 该脚本通过 `[CustomEditor(typeof(Transform), true)]` 全局接管 `Transform` Inspector。  
  若项目中存在其他 Transform 自定义 Inspector，可能出现互斥或覆盖。

- 旋转底层以四元数存储，Inspector 显示为欧拉角；脚本内已将显示角度归一到 `[-180, 180]` 以便编辑。

- 多选旋转批量写入时，会保留未被编辑的轴，避免误覆盖。
