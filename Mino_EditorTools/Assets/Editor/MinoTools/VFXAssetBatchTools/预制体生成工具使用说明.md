# VFXAssetBatchTools 使用说明

## 1. 工具定位

`VFXAssetBatchTools` 是一组面向特效资源生产流程的批处理工具，聚焦于以下三个高频场景：

- Prefab 深度复制（含依赖资源复制与引用重定向）；
- Prefab 及依赖资源批量重命名；
- 贴图导入格式批量规范化（512 / 256 / 128）；
- 重复贴图扫描、材质引用合并与删除（详见 `重复贴图清理工具使用说明.md`）。

统一菜单入口：

- `Tools/MinoTools/特效资源工具/深度复制Prefab`
- `Tools/MinoTools/特效资源工具/重命名Prefab`
- `Tools/MinoTools/特效资源工具/重复贴图清理`
- `Tools/MinoTools/特效资源工具/贴图格式化/512`
- `Tools/MinoTools/特效资源工具/贴图格式化/256`
- `Tools/MinoTools/特效资源工具/贴图格式化/128`

---

## 2. 命名与结构说明

当前目录与脚本采用“按能力直观命名”的方式，降低维护理解成本。

- 文件夹：`VFXAssetBatchTools`
  - 强调这是“特效资源批处理工具集”，而非仅深拷贝工具。

- 脚本：
  - `VFXPrefabDeepCopyTool.cs`：深度复制 prefab 主流程。
  - `VFXPrefabBatchRenameWindow.cs`：重命名窗口与执行逻辑。
  - `VFXTextureFormatTool.cs`：贴图格式批处理工具。
  - `DuplicateTextureCleaner.cs`：重复贴图清理窗口。

## 3. 功能一：深度复制Prefab

### 3.1 功能效果

对选中的单个 prefab 进行“深度复制”：

- 新建 `xxx_new.prefab`；
- 新建 `xxx_new_dependencies` 依赖目录；
- 复制材质、贴图、动画、模型等依赖资源（按策略过滤）；
- 将新 prefab 及相关资源中的 guid 引用替换到新复制资产。

### 3.2 使用步骤

1. 在 **Project** 视图选中一个 prefab（只能选 1 个）。
2. 点击 `Tools/MinoTools/特效资源工具/深度复制Prefab`。
3. 如提示序列化模式，确认切换为 `ForceText`。
4. 等待执行结束，查看弹窗与 Console 输出。

### 3.3 输出规则

- 新 prefab：`原名_new.prefab`
- 依赖目录：`原名_new_dependencies`
- 目录内会按类型归类到 `Mat / Tex / Ani / Mod`（视复制类型而定）

### 3.4 注意事项

- 必须是 Project 视图中的 prefab 资源，不支持层级实例直接执行。
- 执行前请确保不在 Play 模式。
- 工具会修改并新建资产，建议先提交版本管理后再批量操作。

## 4. 功能二：重命名Prefab

### 4.1 功能效果

按“关键词替换”方式，批量重命名目标 prefab 及其依赖资源名称。

- 支持大小写不敏感匹配；
- 显示依赖列表便于预览影响范围；
- 执行后输出成功/失败数量。

### 4.2 使用步骤

1. 打开 `Tools/MinoTools/特效资源工具/重命名Prefab`。
2. 在窗口中指定 `Prefab`。
3. 输入 `关键词` 与 `新关键词`。
4. 点击“开始重命名”。
5. 根据完成弹窗与 Console 检查结果。

### 4.3 注意事项

- 建议每次先对单个 prefab 验证，再做批量资源。
- 如果目标名称已存在或资产被占用，可能出现部分重命名失败。
- 执行后会刷新 AssetDatabase，建议等待 Unity 导入完成再继续操作。

## 5. 功能三：贴图格式化（512 / 256 / 128）

### 5.1 功能效果

对选中的贴图资源（或文件夹内贴图）批量设置导入参数：

- 最大尺寸限制（512 / 256 / 128）；
- 关闭 mipmap；
- 根据是否含 Alpha 自动设置 Android / iOS 压缩格式；
- 修正大写后缀（`.PNG/.JPG/.TGA` -> 小写）。

### 5.2 使用步骤

1. 在 Project 视图选中贴图或包含贴图的目录。
2. 选择菜单：
   - `贴图格式化/512` 或
   - `贴图格式化/256` 或
   - `贴图格式化/128`
3. 等待处理完成，查看 Console“图片批量格式化完成”日志。

### 5.3 平台格式策略（脚本当前行为）

- Android：
  - 含 Alpha：`ETC2_RGBA8`（部分小图场景使用 `RGBA32`）
  - 不含 Alpha：`ETC_RGB4`
- iOS：
  - 含 Alpha：`PVRTC_RGBA4`（小图或开关条件下使用 `RGBA32`）
  - 不含 Alpha：`PVRTC_RGB4`（小图或开关条件下使用 `RGB24`）

---

## 6. 推荐使用顺序（生产流程）

建议按照以下顺序使用，减少返工：

1. 先执行 **深度复制Prefab**（得到独立资源集）；
2. 再执行 **重命名Prefab**（统一命名规范）；
3. 最后执行 **贴图格式化**（按目标规格收敛贴图设置）。

## 7. 常见问题排查

### Q1：菜单点击无效果

- 检查脚本是否编译通过；
- 检查 Unity 是否完成自动刷新与重导入；
- 检查是否放在 `Assets/Editor` 路径下。

### Q2：深度复制提示请选择 prefab

- 当前选中对象不是 Project 视图 prefab 资源；
- 需在 Project 面板选中具体 prefab 资产再执行。

### Q3：重命名有失败项

- 资源重名冲突；
- 资源被占用或只读；
- 失败详情会在 Console 中输出路径与错误信息。

### Q4：贴图格式化后效果异常

- 先核对是否误选了不应压缩的贴图；
- 再核对是否选择了过低尺寸档位（128/256）。
