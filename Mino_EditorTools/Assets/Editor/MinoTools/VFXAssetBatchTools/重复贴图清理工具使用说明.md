# 重复贴图清理工具 使用说明

## 1. 工具定位

`DuplicateTextureCleaner`（原 `ClearDuplicateTexture.cs`）用于在 Unity 工程中查找 **像素内容相同** 的重复 `Texture2D`，合并 **材质** 中的贴图引用，并安全删除勾选的多余贴图。

统一菜单入口：

**Tools → MinoTools → 特效资源工具 → 重复贴图清理**

---

## 2. 推荐流程

```text
扫描重复贴图 → 替换材质贴图引用 → 核对列表 → 删除已勾选
```

| 步骤 | 说明 |
|------|------|
| 1. 扫描 | 在选定范围内查找贴图，按像素 MD5 + 尺寸 + Wrap 模式分组 |
| 2. 替换 | 将材质里指向「重复贴图」的引用改为同组「保留贴图」 |
| 3. 删除 | 勾选确认后删除；删除前会检测引用并二次确认 |

---

## 3. 扫描范围（指定文件夹）

窗口顶部 **扫描范围** 区域支持两种模式：

| 模式 | 说明 |
|------|------|
| **EntireAssets（整个 Assets）** | 扫描工程内全部贴图（默认） |
| **SpecificFolder（指定文件夹）** | 仅扫描该文件夹及子目录下的贴图 |

指定文件夹时的操作：

1. 将 **范围模式** 设为 `SpecificFolder`。
2. 通过 **目标文件夹** 拖拽 Project 中的文件夹，或先在 Project 选中文件夹后点 **使用 Project 选中文件夹**。
3. 点击 **扫描重复贴图**。

说明：

- 指定文件夹模式下，**仅在文件夹内部** 互为重复的贴图会进入列表（不会与文件夹外的贴图比对）。
- **保留贴图** 为同组内在该文件夹内 **先扫到** 的那一张。
- 路径会写入 `EditorPrefs`，下次打开窗口自动恢复。
- **替换材质 / 删除** 仍作用于本次扫描得到的重复组，与扫描范围设置无关。

---

## 4. 界面说明

- **扫描范围**：选择整个 Assets 或指定文件夹。
- **扫描结果**：显示范围、扫描数量、重复数量、保留组数量。
- **重复贴图列表**：每行显示预览、重复路径、对应保留路径。
- **哈希失败提示**：无法计算像素的贴图会跳过，并在 Console 输出警告。

---

## 5. 重复判定规则

对每张贴图：

1. 临时开启可读、无压缩并 Reimport（计算后恢复）。
2. 读取 `GetPixels32()` 计算 MD5。
3. 组合 key：`MD5 + 宽 + 高 + wrapModeU + wrapModeV`。
4. 同 key 下 **先扫描到** 的贴图为保留贴图，其余进入重复列表。

---

## 6. 注意事项

### 6.1 引用范围

- **替换** 当前仅处理 **Material** 资源中的 `Texture2D` 引用。
- **场景、Prefab、粒子、ScriptableObject** 等引用需自行确认；删除前工具会尝试检测工程内引用并提示。

### 6.2 删除安全

- 删除前弹出确认框，列出待删路径（最多预览 8 条）。
- 若检测到仍有资源引用该贴图，会警告并允许你选择是否继续删除。
- 建议务必在删除前完成「替换材质贴图引用」。

### 6.3 性能

- 扫描会对每张贴图做导入设置临时调整（各 2 次 Reimport），贴图多时较慢。
- 已做 **哈希缓存**：替换材质时不会重复计算 MD5。
- 扫描与替换均支持 **进度条**，可取消。
- 大工程建议先用 **指定文件夹** 缩小范围，例如 `Assets/Art/VFX/Textures`。

### 6.4 保留策略

- 默认保留 **扫描顺序中第一张** 贴图，不一定是路径最优或引用最多的一张。
- 删除前请根据列表中的「保留」路径人工确认。

---

## 7. 本次优化摘要（P0 + 文件夹扫描）

1. **哈希缓存**：`path → key` 字典，替换材质时复用，避免二次 Reimport。
2. **删除安全**：引用检测 + 确认对话框 + `StartAssetEditing` 批量删除。
3. **扫描范围**：`FindAssets("t:Texture2D")` 替代全路径逐个 Load。
4. **进度条**：扫描 / 替换可显示进度并取消。
5. **空哈希处理**：失败贴图单独记录，不参与错误合并。
6. **异常日志**：`catch` 不再静默，输出路径与异常信息。
7. **列表只读预览**：避免 ObjectField 误拖拽改引用。
8. **菜单对齐**：迁入 `Tools/MinoTools/特效资源工具`。
9. **列表信息增强**：显示保留贴图路径、扫描统计。
10. **指定文件夹扫描**：支持仅扫描 Assets 下某一文件夹（含子目录），路径可记忆。

## 9. 常见问题

**Q：扫描很慢？**  
A：像素哈希需临时 Reimport，属正常现象；请将 **范围模式** 设为「指定文件夹」，只扫目标目录。

**Q：文件夹外的相同贴图为什么没进列表？**  
A：指定文件夹模式只在目录 **内部** 查重，不与目录外贴图比对。若需全工程去重，请用「整个 Assets」模式。

**Q：替换后 Prefab 仍 Missing？**  
A：Prefab 内引用未自动替换，需手动处理或使用其它引用修复工具。

**Q：同图不同 Wrap 未判重复？**  
A：当前 key 包含 Wrap 模式，属于设计行为；若需纯像素去重可调整 key 规则。

**Q：菜单找不到？**  
A：确认脚本在 `Assets/Editor` 下且编译无报错，路径为 **Tools → MinoTools → 特效资源工具 → 重复贴图清理**。
