# 贴图检测工具使用说明

本文档用于指导你使用贴图检测工具 `TextureSizeCheckWindow`。

## 1. 工具信息

- 脚本路径：`Assets/Editor/TextureCheck/TextureSizeCheckWindow.cs`
- 菜单入口：`Tools/资源检测/贴图大小检测工具`

主要能力：

- 扫描项目贴图分辨率（宽高）
- 扫描贴图磁盘大小（B/KB/MB/GB）
- 读取 Import `Max Texture Size`
- 按图片格式过滤
- 定位超阈值资源
- 导出 Markdown 报告

---

## 2. 使用流程

1. 打开菜单：`Tools/资源检测/贴图大小检测工具`
2. 设置阈值和格式过滤
3. 点击 `开始扫描`
4. 查看汇总与详细列表
5. 如需归档，点击 `导出Markdown报告`

---

## 3. 参数说明

- `宽度阈值`：宽度超过该值即告警
- `高度阈值`：高度超过该值即告警
- `磁盘大小阈值(MB)`：源文件体积超过该值即告警
- `仅显示超阈值项`：是否只展示告警项
- `格式过滤（逗号分隔）`：限制扫描文件后缀

默认已覆盖主流图片格式：

- `.png,.jpg,.jpeg,.tga,.psd,.psb,.tif,.tiff,.bmp,.gif,.exr,.hdr,.dds,.ktx,.ktx2,.webp,.iff`

---

## 4. 结果区解读

### 汇总信息

- 贴图总数
- 超阈值项数量
- 总磁盘体积

### 每条记录字段

- `格式`：后缀
- `分辨率`：`width x height`
- `Import MaxSize`：导入设置最大尺寸
- `文件大小`：磁盘体积
- `分辨率超阈值`：宽或高是否超限
- `体积超阈值`：磁盘体积是否超限

使用 `定位资源` 可快速在 Project 中定位对应贴图。

---

## 5. 报告导出

- 按钮：`导出Markdown报告`
- 报告内容：
  - 扫描时间与阈值
  - 汇总统计
  - 超阈值贴图清单

适合场景：

- 包体优化
- 贴图资产验收
- 版本前巡检

---

## 6. 阈值建议

### UI 贴图

- 分辨率建议：`<= 2048 x 2048`
- 单图体积建议：`<= 1 MB`（按项目可放宽）

### 场景/角色贴图（移动端）

- 分辨率建议：`<= 1024` 或 `<= 2048`
- 单图体积建议：`<= 2 MB`

### 场景/角色贴图（PC）

- 分辨率建议：`2048 ~ 4096`（按画质需求）
- 单图体积建议：结合包体和显存预算控制

---

## 7. 常见问题

### 为什么扫描结果数量偏少

- 检查格式过滤是否过窄
- 某些文件虽是图片后缀，但未被 Unity 识别为 `Texture2D`，会被跳过

### 为什么体积不等于运行时显存

当前工具统计的是磁盘文件大小，不是 GPU 运行时显存占用。  
若要做显存维度评估，建议后续补充平台压缩格式与运行时估算逻辑。

### 先处理哪些告警更有效

建议优先顺序：

1. 分辨率和体积都超限的贴图
2. 大体积 UI 贴图
3. 高分辨率但屏幕显示很小的贴图
